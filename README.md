# 夜班诗铺 · POS机里的诗歌

一台夜班收银机。你输入金额，它把没说出口的话印在热敏纸上。

**在线玩：** [https://19960705.github.io/pos-poetry/](https://19960705.github.io/pos-poetry/)

## 怎么玩

- 任意键关掉开机屏，进入柜台
- 数字键输入金额，`Enter` / 确认 出票
- 在刷卡槽上左右拖，或点「模拟刷卡」
- `Esc` / 作废：清空；空单作废会打出盖章小票
- 出票后点「撕下收好」，小票进抽屉
- 特殊金额会换诗：`0.01` `0.00` `4.00` `6.66` `8.88` `12.00` `13.14` `18.80` `20.25` `20.26` `52.00` `99.99`

进入柜台后会有夜班 BGM 和收银机音效。浏览器要先点一下页面才会出声。

## 本地打开

```bash
python3 -m http.server 8765
```

浏览器访问 `http://127.0.0.1:8765`

Three.js 负责柜台和机身，p5.js 负责热敏小票。BGM 由 Suno 生成。
